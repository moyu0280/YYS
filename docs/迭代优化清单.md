# 阴阳师自动化 APP · 迭代优化清单

> 本清单持续滚动更新，每项带优先级：P0（MVP 必须）/ P1（近期）/ P2（长期）。
> 状态：`待做` / `设计中` / `已落地`。

---

## 一、稳定与容错（Stability）

- [P0] **返回元素识别器**：区分"页面回退箭头"与"翻页箭头/其他箭头图标"，避免误点；左上角箭头与右上角 X 双模板 + 形状识别。
- [P0] **弹窗优先拦截**：游戏内广告/公告/活动弹窗频繁，主流程前先跑"弹窗识别器"清场，避免遮挡。
- [P0] **执行后校验**：每步点击后回读屏幕确认是否生效，失败自动重试 N 次再降级（OCR/VLM）。
- [P0] **加载/过场处理**：识别"加载中"文本或画面静止，等待完成后再读屏，杜绝"点太快"。
- [P1] **网络抖动自恢复**：断线重连弹窗、卡顿自动检测并恢复。
- [P1] **死循环熔断**：同一状态连续 N 次未推进 → 暂停并告警，防止无限重试。
- [P2] **跨机型/分辨率适配**：不同分辨率、刘海屏、折叠屏的坐标映射与缩放校准。

## 二、版本与知识保鲜（Knowledge）

- [P0] **版本自动检测**：登录页/设置-关于读取版本号，版本与知识库不一致时暂停并提示更新。
- [P1] **知识刷新流水线**：版本更新 → 自动抓官方公告 → 更新界面词典/流程库 → 标记旧条目失效。
- [P1] **元素漂移自愈**：版本更新导致 id/文本变化时，用 OCR/VLM 自动重新定位并回写词典，无需人工逐条改。
- [P1] **活动模板热更新**：新活动云端下发模板，不发版即可跑。
- [P2] **知识库版本 diff**：对比新旧版本变化，自动生成"变更摘要"供维护者核对。

## 三、AI 智能度（Intelligence）

- [P0] **模型路由**：本地小模型处理高频简单判断（是否加载中/是否弹窗），云端大模型只处理复杂场景，省时省钱。
- [P1] **多模态细粒度**：从"整屏描述"升级为"按区域理解 + 目标检测（返回键/按钮框定位）"。
- [P1] **失败学习闭环**：失败案例沉淀进知识库，同类问题下次直接命中规则，不再重复犯错。
- [P1] **少样本适配新活动**：给 VLM 看新活动截图 + 少量标注，自动生成任务步骤草稿，人工微调后上线。
- [P2] **本地小模型微调**：用历史"截图+决策"数据轻量微调，降低云端依赖（保鲜仍靠知识库）。

## 四、安全与拟人（Safety）

- [P0] **危险操作护栏**：消耗勾玉/御魂/金币、购买、分解、删除等敏感操作白名单 + 二次人工确认。
- [P1] **拟人化行为建模**：点击坐标抖动、操作间隔随机化、节奏模拟真人，避免机械规律。
- [P1] **运行时长/频率限制**：设置每日上限，避免异常行为模式被风控。
- [P1] **行为画像监控**：记录操作序列，检测连续失败/异常模式，自动熔断。
- [P2] **隐私最小化**：截图本地处理后只上传必要结构化信息，脱敏可配置。

## 五、体验与运维（UX / Ops）

- [P1] **运行报告**：完成/失败摘要推送到手机通知。
- [P1] **截图回放 + 断点续跑**：失败时回放最后 N 步，支持从任意任务续跑。
- [P1] **手动接管/混合模式**：人随时接管继续，或"人做前半段、AI 做后半段"。
- [P2] **低功耗/后台**：屏幕常亮控制、省电策略、后台保活。

---

## 已吸收的硬性要求（不可妥协）

1. 不读取游戏内存、不 Hook、不改包（只有屏幕 + 无障碍）。
2. **禁用系统返回键**：所有返回/关闭只走游戏内左上角箭头 / 右上角 X。
3. AI 必须知道**最新版本**阴阳师内容：走"知识库 + RAG + 版本管理"保鲜。

---

## 追加优化点（本轮细化：领域知识层 / 返回识别器 / MVP 后产生）

- [P0] **页面指纹分级**：`fingerprint` 用 `must_text + any_text` 组合而非单一文本，防止文案微调导致整页误判。
- [P0] **每步可观测性**：`reportFailure/reportDone` 落库每步截图 + 状态，支持回放定位。
- [P0] **版本号双轨**：区分"客户端版本"与"资源热更 build"，热更不阻断、大版本才暂停。
- [P1] **相对坐标 + 安全区校准**：刘海/挖孔/状态栏偏移的机型适配统一封装。
- [P1] **元素自愈阈值**：`unknown` 触发条件（连续失败次数/时间窗）与回写校验。
- [P1] **返回误点率监控**：记录"点击返回后页面未变化"比例，超阈值告警并复盘。
