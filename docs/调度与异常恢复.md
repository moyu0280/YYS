# 调度与异常恢复详细设计

> Agent 的"计划与运维"：什么时间跑什么、跑挂了怎么续、卡死了怎么停。

---

## 1. 每日编排（Daily Planner）

- 以阴阳师 **每日 05:00 刷新**为界划分"游戏日"；
- 任务按**依赖 + 时间窗 + 优先级**排序：
  ```
  05:00 刷新 → 签到 → 领体力/勾玉 → 悬赏 → 御魂(耗体力)
  → 探索 → 结界突破 → 百鬼 → 寮任务/捐赠
  → 逢魔之时(17:00 后) → 报告
  ```
- 限时任务（逢魔/石距）挂在**时间窗**上，窗口未到则跳过/延后。

## 2. 任务依赖与前置

- `preconditions`（体力、次数、解锁、无弹窗）在执行前校验；
- 不满足 → 跳过并记录原因，不硬跑；
- 体力不足这类"可再生"资源可配置"等待再试"或"今日放弃"。

## 3. 断点续跑

- 每个任务持久化"当前进度"（跑到第几步、卡在哪个页面）；
- 中断（闪退/手动停止/异常）后，下次从**最近一个已完成步骤之后**续跑；
- 同一页面重试超阈值 → 跳过该任务，标记"需人工"，不阻塞后续任务。

## 4. 熔断与熔断恢复

- **死循环熔断**：同一状态连续 N 次未推进 → 暂停该任务并告警；
- **全局熔断**：连续 M 个任务失败 → 停止整批，避免机械重试被风控；
- 熔断后记录现场（截图 + 屏幕快照）供人工排查。

## 5. 手动接管 / 混合模式

- 任何时刻可"暂停 → 人操作 → 继续"；
- 混合模式：人做前半段（如登录、斗技），AI 做后半段；
- 接管点即断点，续跑从人停止处继续。

## 6. 重试策略

- 单步：失败 → 立即重试 ≤2 次 → 换定位方式 → 升 AI 轨；
- 任务级：失败 → 标记待处理，跳过，不阻塞后续；
- 批次级：全部跑完后统一出报告（成功/失败/需人工）。

## 7. 运行报告

- 每批结束生成摘要：各任务状态、耗时、失败原因、需人工项；
- 通过通知推送 + 本地日志 + 截图回放三通道留痕。
