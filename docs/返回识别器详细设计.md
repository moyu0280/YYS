# 返回识别器详细设计（禁用系统返回键）

> 对应主方案 §4.1。硬约束：**任何情况下不得调用系统返回键**，所有"返回上一页/关闭弹窗"只点游戏内 UI。

---

## 0. 硬约束

- 代码层禁用 `performGlobalAction(GLOBAL_ACTION_BACK / HOME)`；
- 所有返回/关闭走游戏内 **左上角箭头**、**右上角 X** 或 **文字"返回/关闭"按钮**；
- 找不到游戏内返回入口 → **暂停交人工**，绝不降级到系统返回键。

---

## 1. 返回/关闭元素分类

| 类型 | 含义 | 典型位置 |
|---|---|---|
| `arrow_back` | 回上一页（朝左箭头 `<`） | 左上角 |
| `close_x` | 关闭弹窗/面板（`×`） | 右上角 |
| `text_back` | 文字按钮（"返回/关闭/取消"） | 页面内 |

---

## 2. 定位优先级（由高到低）

1. **resource-id**：词典已登记（含 `back/close/return` 关键词或页面词典 id）；
2. **text / desc**：文本为"返回 / 关闭 / 取消 / ×"；
3. **区域 + 形状**：左上角箭头、右上角 X（模板匹配 / 轻量分类器）；
4. **VLM 目标检测**：截图让多模态模型框出"返回箭头/关闭按钮"（最慢，兜底）；
5. **全部失败** → 暂停交人工（附截图与原因）。

---

## 3. 区域定义（机型无关相对坐标）

- 左上返回箭头：`x ∈ [0.02, 0.10]`，`y ∈ [0.03, 0.12]`
- 右上关闭 X：`x ∈ [0.88, 0.98]`，`y ∈ [0.03, 0.12]`

> 相对坐标按屏幕有效区换算；需排除状态栏/刘海/挖孔偏移（用 `getWindowVisibleDisplayFrame` 或安全区校准），避免点到状态栏。

---

## 4. 识别技术

| 手段 | 适用 | 说明 |
|---|---|---|
| UI 树特征 | 首选 | 节点类型 `ImageView/Button` + 位于角区域 + id 关键词 |
| 形状识别 | 兜底 | 模板匹配 `<` 和 `×`，或轻量二分类模型 |
| OCR | 补充 | 识别"返回/关闭/×"文字 |
| VLM 目标检测 | 最后 | 复杂/陌生页，输出按钮框坐标 |

---

## 5. 决策状态机（返回流程）

```
requestBack()
 ├─ 查 page.back_action（词典已定义）→ 直接定位该类型
 ├─ 按优先级找元素 → 命中 → click → 校验页面变化
 │        ├─ 变化成功 → done
 │        └─ 未变化 → 重试(≤N) → 换下一优先级
 ├─ 无词典 → 依序试 arrow_back 区域 → close_x 区域 → text_back
 └─ 全失败 → 暂停交人工（附截图）
```

---

## 6. 校验与自愈

- 点击后对比**页面指纹**（`page.fingerprint`）变化确认是否真的返回；
- 未变化 → 可能误点其他元素 → 记录 → 换定位方式重试；
- 同一 `back_action` 连续失败 N 次 → 标 `stale` → 触发知识刷新流水线重新定位并回写。

---

## 7. 防误点规则（关键）

- **回退箭头 vs 翻页箭头**：翻页箭头通常在列表中部/底部，回退箭头固定左上角；只认"左上角 + 朝左 `<`"。
- **关闭 X vs 其他 ×**（删除/取消选中）：形状识别只在上文两个角区域内启用，且优先词典 id/文本。
- **展开/收起箭头（▽/△）不归为返回**：只有朝左 `<` 才执行"回退"。

---

## 8. 执行器接入（代码层保障）

- `ActionExecutor` 不提供 `back()` 方法；
- 唯一返回入口是 `requestBack()`，内部委托本识别器；
- 全局拦截：任何模块调用系统返回 → 编译期/运行期拦截，绝不执行。

---

## 9. 落地优先级

1. **P0**：三类元素定位 + 区域定义 + 决策状态机；
2. **P0**：代码层禁 back + `requestBack()` 转译（见 MVP 骨架 `ActionExecutor` / `BackRecognizer`）；
3. **P1**：形状识别 / VLM 目标检测兜底；
4. **P1**：`stale` 自愈回写。
