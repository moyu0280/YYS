# 安全与拟人设计

> 两条底线：不碰内存（已由架构保证）+ 尽量降低风控风险（诚实说明：无法保证不封号）。

---

## 1. 危险操作护栏（P0，强制）

| 类型 | 处理 |
|---|---|
| 消耗勾玉/御魂/金币 | 默认拦截，弹人工确认 |
| 购买/充值 | 一律不执行，交人工 |
| 分解/返还/献祭式神 | 拦截 + 确认 |
| 删除好友/退寮 | 拦截 |
| 发送消息/发言 | 默认不自动发 |

实现：`Action` 层加 `risk` 标记；`TaskEngine` 执行前查白名单，命中危险项 → 暂停交人工。

## 2. 拟人化行为建模

- 点击坐标**抖动**（±几像素随机）；
- 操作间隔**随机化**（在基准值上叠加随机）；
- 滑动轨迹非直线（Path 加扰动）；
- 任务节奏模拟真人（不机械等长间隔、不秒级连点）。

## 3. 运行时长与频率限制

- 每日运行总时长上限（可配置）；
- 单任务/单玩法次数上限（如御魂最多 N 次）；
- 连续运行超过阈值 → 自动暂停冷却。

## 4. 行为画像监控

- 记录操作序列，检测：连续失败、机械规律、异常高频；
- 命中异常模式 → 自动熔断 + 告警。

## 5. 隐私最小化

- 截图/OCR 默认**本地处理**；
- 需上云（VLM/大模型）时先脱敏（昵称/聊天/数字打码）；
- 登录、验证码、支付一律不碰，交人工。

## 6. 合规声明（App 内明示）

- 首次引导明确：本工具为屏幕级自动化，可能违反游戏用户协议，存在封号风险；
- 用户显式确认后才启用无障碍服务；
- 提供"一键停止"入口。
